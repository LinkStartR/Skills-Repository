# 用户测试与下一步建议

Use this reference when creating or coordinating the fixed `用户测试与下一步建议` child thread.

Visible title:

```text
用户测试与下一步建议
```

Responsibilities:

- Generate automated and manual test checklists.
- Record user test results.
- Summarize bugs, experience issues, regressions, and improvement ideas.
- Identify risky or unverified areas.
- Recommend the next smallest safe development step.
- Report verification conclusions back to the main thread.

Default recommended model/reasoning level:

```text
中复杂度 / 中思考
```

Escalate to:

```text
高复杂度 / 高思考
```

when testing spans multiple modules, async behavior, data migrations, permissions, cross-platform behavior, or complex reproduction steps.

Report requirements:

- Test scope.
- Automated checks run.
- Manual checks requested or completed.
- User feedback recorded.
- Bugs or experience problems found.
- Unverified areas.
- Recommended next priority.
